# helium-macos
macOS packaging & development tooling for the
[Helium Browser](https://github.com/imputnet/helium).

## This fork

This fork builds an Apple Silicon version of Helium with
[Helium PR #2367](https://github.com/imputnet/helium/pull/2367) applied.
It adds an optional **Show address bar in sidebar** setting for vertical tabs
in Zen/frameless mode, placing the address bar and navigation controls at the
top of the sidebar.

The pull request is closed and unmerged upstream, so this is an unofficial
build. Builds are produced by GitHub Actions and are not signed or
notarized by the Helium project.
